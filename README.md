# NerdClock – Updates

Die **NerdClock** ist die Bitcoin-Uhr von [Nerdminer.de](https://nerdminer.de).

Dieses Projekt enthält **keinen Quellcode**, sondern nur, was die NerdClocks über das WLAN abholen:

- **Releases** – fertige Firmware (`nerdclock.bin`) für die automatischen Updates
  (jede NerdClock prüft beim Einschalten und nachts um 3 Uhr, ob es eine neue Version gibt)
- **events.json** – Bitcoin-Konferenzen und Treffen für den Screen „Bitcoin-Events“
- **news.json** – Bitcoin-News (folgt)

We do Bitcoin.
